# 推薦與位置計算

## 1. 起始房間選擇

以基礎幾何配對的 confidence 計算各房間的加權連接度，優先選擇加權連接度較高者，同分時以 room ID 排序。DA3 的 layout-only 備援配對不參與這一步；只有備援配對時，加權連接度皆為 0，以 ID 決定起始順序。

## 2. 下一個房間排序

保留「一端已放置、另一端未放置」的連接，排除 `excluded_pair_ids` 後按 confidence 降冪排序。同一個待加入房間可以經由不同連接對象產生多筆推薦。

confidence 綜合相對角度品質、牆面接觸比例、候選歧義及影像幾何風險。正規化 DA3 配對用於備援時，以 probability×0.25（最低 0.001）計算分數，資料門檻為 0.01。這是本套件的備援規則，**不是任何上游模型的通用連通判斷門檻**；呼叫端需先依資料來源規格選擇可用配對。

分數只用於排序，不是經校準的拼接正確率。每次配置更新後需重新查詢推薦，不提供一次固定的全樓層順序。

## 3. 位置候選

有完整影像幾何時，依相對旋轉找出符合輪廓主軸的方向，按相機間方位預選牆面，計算牆線接觸位移並產生沿牆滑移方案。使用相對方向而不是影像平移向量的長度恢復 layout 尺度下的位置。

沒有可用幾何位置但有正規化配對分數時，使用輪廓的四個主軸方向產生 layout-only 候選，並標記為較高風險。沒有配對資料時，不自行建立所有房間之間的連接。

## 4. 位置評分

位置候選依目前所有已放置輪廓評分，包括：

- 重疊面積比例及與連接房間的距離。
- 與原始方向／位置量測的偏差。
- 對應牆面距離、接觸長度及端點距離。
- 基礎候選代價與沿牆滑移代價。

代價越低越優先。位置建議可包含內部吸附所選的位置；此評分不構成對外的衝突檢查服務，輸出不含加入的通過／拒絕決定。

## 5. 預覽

依指定的整體位置與角度轉換房間輪廓，再與既有配置組合。此步驟不吸附、不評分、不檢查重疊或間距，也不重新最佳化其他房間。

演算法設定隨版本固定於 `src/room_assembly/defaults.json`。輸入輪廓的尺度、配對品質及方向歧義會影響結果；整合端需自行決定確認與保存條件。
